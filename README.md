## shutdown

Пакет для безопасного (graceful) завершения работы нескольких компонентов с контролем таймаутов на каждом этапе.

## Установка

```bash
go get github.com/ethernetuser/shutdown
```

## Поведение

- Компоненты завершаются последовательно в порядке, переданном в New.
- Для каждого компонента действует свой таймаут (timeoutPerInstance). Если он превышен, возвращается ошибка ErrPerInstanceTimeout.
- Общий таймаут (timeoutGlobal) ограничивает время всей операции. При его истечении возвращается ErrGlobalTimeout.
- Все ошибки (как от самих компонентов, так и от таймаутов) собираются и возвращаются как одна через errors.Join.
